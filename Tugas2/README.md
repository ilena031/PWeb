# Tugas 2 – Tabel dan Form Login

Tugas kedua ini tentang pengenalan elemen tabel sama form di HTML. Ada dua bagian utama di satu halaman:

1. **Tabel Nilai** — tabel data siswa (Robby, Rendi, Alfian) beserta nilai Kimia, Fisika, dan Biologi. Pake `rowspan` dan `colspan` buat header-nya.
2. **Form Login** — form sederhana dengan input username, password, checkbox "Remember Me", dan tombol submit.

## Struktur Folder

```
Tugas2/
└── index.html        # Halaman tabel + form login
```

## Fitur

- Tabel dengan header merge (`rowspan`, `colspan`)
- Hover effect di baris tabel
- Form login sederhana dengan styling rounded
- Semua CSS internal (di dalam `<style>`)
