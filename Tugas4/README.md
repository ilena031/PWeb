# Tugas 4 – Landing Page "Crumb & Craft" (CSS Dasar)

Tugas keempat ini bikin landing page untuk kursus baking fiktif bernama **Crumb & Craft**. Fokusnya di penerapan CSS murni (tanpa framework) untuk bikin layout yang menarik dan interaktif.

Website ini punya banyak section: Hero, About, Courses, How to Join, Testimonials, dan lain-lain. Semua styling ditulis inline di dalam tag `<style>` di file HTML.

## Struktur Folder

```
Tugas4/
└── index.html        # Single-page landing (HTML + internal CSS)
```

## Fitur

- Navbar fixed dengan blur effect
- Hero section dua kolom (teks + card)
- Floating blob animations
- Card kursus dengan hover effects
- Section dark mode (How to Join)
- Responsive design
- Font dari Google Fonts (Playfair Display, DM Sans, Caveat)
