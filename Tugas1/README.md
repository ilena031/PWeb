# Tugas 1 – Halaman CV / Curriculum Vitae

Tugas pertama dari mata kuliah Pemrograman Web. Di tugas ini aku bikin halaman CV sederhana pake HTML dan CSS murni (internal style). Layout-nya dibagi jadi dua kolom: bagian kiri buat info personal (foto, kontak, education) dan bagian kanan buat pengalaman organisasi, project, skills, dan future plan.

## Struktur Folder

```
Tugas1/
├── index.html        # Halaman utama CV
└── Banun.jpg         # Foto profil
```

## Fitur

- Layout dua kolom (sidebar kiri + konten kanan)
- Foto profil rounded
- Bagian kontak, pendidikan, pengalaman organisasi, proyek, skill, dan achievement
- Styling internal (CSS di dalam `<style>`)

## Cara Buka

Tinggal double-click file `index.html` di browser.
