# Tugas 7 – Login Page dengan Bootstrap

Tugas ketujuh ini bikin halaman login menggunakan framework **Bootstrap 5**. Desainnya dibuat senada sama Tugas 6 (tema coklat-putih minimalis) tapi pake komponen Bootstrap buat layout dan form-nya.

## Struktur Folder

```
Tugas7/
├── index.html        # Halaman login
├── style.css         # Custom CSS override Bootstrap
└── script.js         # Validasi form + toggle password
```

## Fitur

- Halaman login centered (email + password)
- Toggle show/hide password (icon mata)
- Validasi client-side (format email, panjang password)
- Checkbox "Ingat saya"
- Link "Lupa kata sandi?"
- Tombol "Masuk dengan Google" (placeholder)
- Link ke halaman registrasi
- Responsive di semua ukuran layar

## Teknologi

- HTML5
- Bootstrap 5.3 (via CDN)
- Bootstrap Icons (via CDN)
- Custom CSS
- Vanilla JavaScript
