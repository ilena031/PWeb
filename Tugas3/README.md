# Tugas 3 – Website Profil Sekolah (Ignatius Global School)

Tugas ketiga ini bikin website profil sekolah SMA Ignatius Global School (IGS) Palembang. Pake TailwindCSS buat styling-nya supaya lebih cepat dan responsive. Website ini punya beberapa section:

- **Navbar** — fixed di atas, ada logo sekolah + navigasi (Beranda, Prestasi, Galeri, Info PPDB)
- **Hero Section** — tagline "The First Choice, To The Best Future"
- **Prestasi** — grid card dari berbagai prestasi siswa (OSN, Basket, Essay, Bahasa Jepang, Bahasa Jerman, Duta Pariwisata)
- **Galeri Kegiatan** — foto-foto kegiatan sekolah (Classmeet, Bukber, Ramadhan, Natal, Ekaristi) dengan hover overlay
- **Footer** — link sosmed dan website resmi IGS
